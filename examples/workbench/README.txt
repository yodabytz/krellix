Workbench is a starter theme for Krellix.

Keep this folder named workbench, with theme.json immediately inside.
Put the whole folder in:
  Linux or macOS: ~/.config/krellix/themes/
  Windows: %LOCALAPPDATA%\krellix\themes\
  Windows portable alternative: themes\ next to krellix.exe

On Linux, use $XDG_CONFIG_HOME/krellix/themes/ if XDG_CONFIG_HOME is set.
In Krellix, select workbench under Settings > Appearance > Theme.
If it is not listed yet, close Settings and reopen it.

Edit theme.json in a plain-text editor. No artwork or extra fonts are required.
Guide: https://cerberix.org/extras/krellix/themes/#build-a-theme
