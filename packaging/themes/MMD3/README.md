# MMD3

MMD3 uses sculpted silver frames, blue glass panels, cyan chart traces, and
a decorative animated footer. This is a download-only theme, not part of the
Krellix application bundle.

Install the **MMD3** folder in your user theme directory and select **MMD3**
under Settings > Appearance. See the
[theme guide](https://cerberix.org/extras/krellix/themes/#build-a-theme) for
the paths on Linux, macOS, and Windows.

The original artwork is laid out for a 240-pixel panel. MMD3 does not change
your saved panel width, chart overrides, or monitor order. Older builds
that tile footer artwork are best viewed at 240 pixels. The footer is a
decorative loop, not a network status indicator. It uses the static
footer when theme animation is set to Off.

The OK status in an updated KrellHealth plugin uses the supplied heart art.
Other health states use the plugin's usual icons. Host and clock remain
separate monitors; installing this theme does not change telemetry or plugins.
