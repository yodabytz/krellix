# Ubuntu-Ember

Ubuntu-Ember is a standalone Krellix theme with orange outlines, aubergine
panels, and a Circle of Friends badge for KrellHealth's OK state.

Extract `Ubuntu-Ember` into your user themes directory and select it under
Settings > Appearance. The [theme guide](https://cerberix.org/extras/krellix/themes/#build-a-theme)
lists the theme directory on each platform.

Your saved panel width and chart height stay in control. The corner artwork
is transparent; on builds without the optional `window_shadow` metric,
the operating system may still draw its normal window shadow.
