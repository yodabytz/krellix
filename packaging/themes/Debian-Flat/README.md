# Debian-Flat

A static, download-only theme with charcoal panels, raspberry-red borders,
and a Debian-branded header. Install the **Debian-Flat** folder in your user
theme directory and select it in Settings > Appearance. See the
[Krellix theme guide](https://cerberix.org/extras/krellix/themes/#build-a-theme).

Panel icons use the app's existing title slots. In an updated KrellHealth
plugin, the Debian spiral replaces the healthy heart. Other health states
keep their original icons and labels. No theme assets contain live readings,
and the theme does not change saved width, monitor order, or chart overrides.
