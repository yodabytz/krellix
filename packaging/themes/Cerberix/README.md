# Cerberix

A standalone Krellix theme with violet panels, lime chart accents,
a Cerberix top banner, and an animated lime footer.

Extract the `Cerberix` directory into the user themes directory
(`~/.config/krellix/themes/` on Linux and macOS,
`%LOCALAPPDATA%\krellix\themes\` on Windows). Select `Cerberix` under
Settings > Appearance. Use the current Krellix build for header dragging
and the animated footer. Select Off under Theme animation for a static footer.
