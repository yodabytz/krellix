# Arch Azure

Arch Azure is a standalone Krellix theme with graphite panels, Arch-blue
charts, rounded corners, and artwork for KrellHealth.

Extract the `Arch-Azure` folder into your user themes directory. Use
`~/.config/krellix/themes/` on Linux and macOS, or
`%LOCALAPPDATA%\krellix\themes\` on Windows. Select `Arch-Azure` under
Settings > Appearance. The current Krellix renderer supports the intended
transparent corners and slim sliders. The theme does not change your saved
chart height or panel width.
