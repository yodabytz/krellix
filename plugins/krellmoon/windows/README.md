# KrellMoon for Windows

With Krellix closed, verify the signed ZIP, extract it, then run
`./install-kam-moon.ps1 -KrellixDirectory C:/path/to/preview.6/Krellix`.
Open Settings > Plugins > Krellmoon and enable the panel. The original
phase artwork is embedded in the DLL and requires no separate install.
The local panel uses the system clock, works offline, and supports the
Southern Hemisphere setting. Remote Krellix windows do not use local data.
